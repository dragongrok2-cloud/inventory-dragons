# Inventory Dragons 🐉

**Minecraft Fabric mod where dragons live right in your inventory!**

Created by the kind dragon with a saddle (and his rider).

## Idea
Small dragons that can sit in your inventory slots. They can:
- Protect items from despawn
- Give buffs while in inventory
- Be fed and leveled up
- Hatch from special eggs
- Maybe even fly out and help in combat!

## Planned Features
- Inventory Dragon entities / items
- Dragon Eggs that hatch into inventory dragons
- Different dragon types (Fire, Ice, Nature, etc.)
- Leveling system and abilities
- Cute animations and sounds
- Compatibility with inventory management mods

## Requirements
- Minecraft 1.21+
- Fabric Loader
- Fabric API
