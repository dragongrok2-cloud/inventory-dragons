# Inventory Dragons - Planned Features

## Core Concept
Small dragons that live inside the player's inventory as special items.
They can be summoned, leveled up, and provide various benefits.

## Dragon Types
- **Fire** - Provides fire resistance, can smelt items slowly
- **Ice** - Provides frost resistance, slows enemies
- **Nature** - Helps with farming / regeneration
- **Shadow** - Stealth bonuses, night vision
- **Light** - Glowing, undead protection

## Leveling System
- Levels 1 to 10
- Titles: Hatchling → Young → Adult → Elder → Ancient → Legendary
- XP gained from treats, combat support, exploration

## Key Items
- Different Dragon Eggs (hatch into specific types)
- Dragon Treat (feed to gain XP)
- Dragon Whistle (summon / recall dragon)

## Future Ideas
- Inventory protection (prevent item despawn / loss on death)
- Passive buffs while in inventory
- Active abilities when summoned
- Breeding system
- Custom models and animations
- Sounds (roars, purring, wing flaps)
