# Inventory Dragons - Features

## Core Concept
Small dragons that live inside the player's inventory as special items.
They can be summoned, leveled up, hatched from eggs and provide various benefits.

## Dragon Types
- **Fire** — Fire resistance, can help smelt
- **Ice** — Frost resistance, slows enemies
- **Nature** — Regeneration / farming help
- **Shadow** — Stealth & night vision
- **Light** — Glowing, undead protection
- **Wind** — Speed, Slow Falling, better mobility

## Leveling System
- Levels 1 to 10
- Titles: Hatchling → Young → Adult → Elder → Ancient → Legendary
- XP from treats, combat support, exploration

## Key Systems Implemented
- **HatchingSystem** — Eggs hatch into specific or random dragons
- **InventoryEvents** — Feeding, passive buffs, protection placeholders
- **DragonLeveling** — XP and titles
- **ModSounds** — Hatch, eat, roar, purr, wings, whistle

## Key Items
- Multiple Dragon Eggs (including Wind)
- Dragon Treat
- Dragon Whistle

## Future Ideas

- Full inventory tick events for passive buffs
- Actual status effects per dragon type
- Custom models, animations and .ogg sounds
