Model & Texture Placeholders
============================

This folder is ready for item models and textures.

Suggested structure later:

assets/inventory-dragons/
  models/item/
    fire_inventory_dragon.json
    ice_inventory_dragon.json
    ...
  textures/item/
    fire_inventory_dragon.png
    ice_inventory_dragon.png
    ...
  textures/entity/
    inventory_dragon_fire.png
    inventory_dragon_ice.png
    ...

For entity models you will also need a geo/model file if using GeckoLib,
or a standard entity renderer + model class.

Currently the mod uses vanilla-like placeholder behavior.
